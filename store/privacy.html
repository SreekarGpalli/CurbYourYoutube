Curb Your YouTube · November 12, 2026

Privacy policy

Curb stores data in your Chrome profile without sync, analytics, or a developer server. Some features send requests directly to YouTube or Google Gemini.

Data on your device

Curb encrypts settings, saved searches, Gemini API keys, and one daily watch-time total in your Chrome profile. Your current intent, tab activity, session timers, pending search handoffs, and cached summaries use Chrome’s temporary extension storage and clear when Chrome closes.

YouTube access

After you select Enable Curb, Curb reads visible video details, playback state, and tab activity to show previews, hide distractions, pause videos, and track session time. It keeps no separate watch history or transcript archive.

Opening a saved search sends its terms to YouTube. Save and get YouTube suggestions places your custom intent in YouTube’s search box. YouTube may receive the text before you submit a search. Hover thumbnail previews may request the selected video’s image from YouTube’s image server using the video ID. Google’s Privacy Policy covers this activity.

Gemini video summaries

If you add your own API key and allow access, choosing Summarize sends the selected public video URL to Google’s Gemini API over HTTPS. Google receives the key to authenticate the request. Curb includes your session intent only if you enable Include my intent in Gemini requests. Curb asks Gemini to skip saving the interaction in project history.

Gemini setup asks you to confirm that you’re 18 or older, using Gemini for work in a supported region, and using your own billing-enabled project with request logging and data sharing off.

Google may retain paid-service requests for policy enforcement or legal obligations. Under its unpaid-service terms, Google may use prompts and responses to improve its services and allow human review. Gemini API terms

Clear your data

In Settings, select Clear local data to reset preferences, delete saved searches, watch time, API keys, and cached summaries, and end the session across tabs. Uninstalling removes Curb’s extension storage. Google manages data it receives under its own policies.

Limited Use

Curb Your YouTube limits its use and transfer of data to providing the features described here, consistent with the Chrome Web Store User Data Policy’s Limited Use requirements. For privacy questions, use the developer contact in the Chrome Web Store listing.
